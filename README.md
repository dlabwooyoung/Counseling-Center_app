# 🎯 고민 해결 센터

어이없는 대답으로 당신의 고민을 "해결"해주는 재미있는 Streamlit 앱입니다! 😄

## 기능

✨ **입력**: 고민을 입력 칸에 작성
🚀 **처리**: "해결해주기" 버튼을 누르면 어이없는 대답이 나옴
🔊 **효과음**: 뾰로롱 효과음 자동 재생
🌙 **디자인**: 어두운 테마에 흰 글씨, 굵은 폰트

## 설치 및 실행

### 1. 라이브러리 설치
```bash
pip install -r requirements.txt
```

### 2. 앱 실행
```bash
streamlit run "Counseling Center_app.py"
```

### 3. 브라우저에서 열기
- 자동으로 `http://localhost:8501`에서 열립니다
- 고민을 입력하고 "해결해주기" 버튼을 클릭하세요!

## 요구사항

- Python 3.7+
- streamlit
- numpy
- scipy

## 특징

🎪 15가지의 어이없는 대답 모음
🌟 매번 다른 대답이 나옴 (무작위 선택)
🔊 뾰로롱 효과음 (프로그래밍으로 생성)
🎨 다크 테마 + 황금색 제목
💬 반응형 인터페이스
